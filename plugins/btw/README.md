# btw

Ask side questions while Yuke works, without changing the main conversation. Answers have searchable history.

## Installation

```sh
yuke plugin add https://github.com/lostcoords/yuke-plugins --folder plugins/btw
```

Run `/reload` while idle.

## Usage

Send a main message first, then ask:

```text
/btw explain the approach you are taking
```

- `/btw` or **Ctrl+K, then B** opens the panel.
- `/btw:history` browses saved answers.
- **Enter** sends a question. **Esc** closes the panel and cancels the request.
